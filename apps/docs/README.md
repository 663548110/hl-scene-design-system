
[RDesign](https://github.com/your-org/rdesign-flutter) 基于 TDesign 适配 Flutter 的企业内部组件库。

## 预览

iOS 请运行项目预览 ↓

## 使用组件

### yaml 引入依赖

```yaml
  dependencies:
    rdesign_flutter:
      path: ../../packages/flutter/rdesign_component
```

### 引入组件代码

```dart
import 'package:rdesign_flutter/rdesign_flutter.dart';
```

## 本地运行官网示例代码

- 在 `apps/docs` 目录运行 `pnpm install` 安装依赖
- 在仓库根目录运行 `npm run docs:dev`
- 或在 `apps/docs` 目录运行 `pnpm run site:dev`
